## ✨ CURRENT FEATURES

* 🌗 **Dual Theme** — Switch between Crimson Red and Cosmic Blue.
* 🧭 **Smart Navigation** — Multi-level navigation and organized game sections.
* 🃏 **Character & Database Pages** — Dedicated pages for characters and game content.
* 📖 **Story Archive** — Explore stories, lore, and world information.
* 🗺️ **World Maps** — Dedicated map sections for multiple games.
* 🎴 **Relic & Equipment Database** — Star Rail relic and equipment information.
* 🐺 **Bangboo Database** — Zenless Zone Zero Bangboo collection.
* 📱 **Responsive Design** — Built to work across desktop, tablet, and mobile.
* ⚡ **Vanilla Frontend** — No heavy framework required.
* 💾 **JSON Data System** — Character and agent data stored separately from the UI.
* 🌐 **GitHub Pages Hosting** — Fully deployed as a static website.
* 🔗 **Custom Domain** — Served through `miyabi-suki.xyz`.

## 🌐 DEPLOYMENT

The website is deployed directly from the `main` branch using **GitHub Pages**.

```text
Git Repository
      │
      ▼
    main
      │
      ▼
 GitHub Pages
      │
      ▼
miyabi-suki.xyz
```

Every update pushed to `main` can be deployed automatically by GitHub Pages.
